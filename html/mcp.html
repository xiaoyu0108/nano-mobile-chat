连接 MCP 工具

已内置几个公开免费的 MCP 和本地「陪伴型」工具，点开即可用；也可以自己添加服务器。开启开关后，聊天里的角色就能主动调用它们。

自己接入（三步）

  1. 准备一个 MCP 服务器地址（Streamable HTTP，形如 https://xxx/mcp）。
  2. 点右上角 ＋，填「名称 + 地址」；需要鉴权就在「令牌」里填你的 Bearer Token。
  3. 保存后点该服务器 → 自动连接并列出工具；把开关打开，聊天里的角色即可调用。

令牌在哪填

  1. 服务器令牌：填在「＋添加服务器」弹窗的「令牌」框里，就是该 MCP 服务商给你的 API Key（Authorization: Bearer ...）。
  2. 代理安全锁（可选）：想让代理只允许你自己用，就在 Worker 端执行 npx wrangler secret put MCP_TOKEN 设一个值；再在浏览器控制台执行 localStorage.setItem('nano_mcp_token','同一个值')。两处一致才放行；不设则代理对访问者开放。

MCP 里还有什么

  1. Nano 原生工具：天气、时间、定位、地图、打开网页、打开 App，本地直接执行，不需要服务器。
  2. 远程 MCP：DeepWiki / GitMCP / Microsoft Learn / Cloudflare Docs，也可以添加自己的服务器。
  3. 那个 JSON：点开任意工具后，文本框里是调用这个工具要传的参数（JSON 对象）。没有参数就保留 {}，改好点「运行」即可测试。

限制

  1. 只支持远程 HTTP（不支持本地 npx stdio 服务器）。
  2. 需要 OAuth 登录的服务器暂不支持，请用 API Key / Bearer。
