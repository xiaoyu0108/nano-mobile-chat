      方式 C · 屏幕速聊（快捷指令 + 服务端）
      

        
需要你自己部署一个 Cloudflare Worker（`push-worker`），部署步骤见 docs/ios-shortcuts.md 的「部署 push-worker」。没有服务端就用上面的方式 B：快捷指令直连你已有的模型接口即可。

        
在任意 App 里双击「辅助触控」运行快捷指令：截屏 → 发到你的服务端 → 回复直接弹在系统窗口里、可继续打字；等你回到小手机后，这几轮会按顺序自动合并进该角色的聊天。Key 只存在服务端，不进快捷指令。

现在人设会自动从 App 同步到服务端：你在 Nano 里切换角色后即时生效，快捷指令里 system 可以直接不填（留空即用当前角色人设）。下面这段是给你需要手动填（方式 B / 自定义）时用的。

        


        

        

          快捷指令怎么搭：

          1) 截屏 → Base64 编码（关掉换行）；

          2) 获取 URL 内容：POST 到上面「接口地址」，头部加 X-Peek-Token: 你的令牌；

          3) 请求体选 文件，引用一个 文本 动作：

          {"chatId":"<角色ID>","system":"<人设>","image":"data:image/jpeg;base64,<截图base64>"}；

          4) 获取字典值 取 reply → 显示提醒 弹出；

          5) 接着 要求输入 拿到你打的字，把 image 换成 text 再发一轮 → 循环，形成连续对话。
