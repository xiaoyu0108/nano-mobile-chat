窥屏
SCREEN PEEK
让 TA 看看你的屏幕
窥屏不是监视，是让角色看你正在看的内容，然后像坐在你旁边一样吐槽、关心、吃醋。选一个方式开始。
谁来看
最简单 电脑上玩
点下面的按钮 → 选择「整个屏幕」→ 完成。TA 每 30 秒看一次，点评会直接写进你们的私聊。
需要电脑 Chrome / Edge。手机网页端拿不到录屏权限，请用下面的手机方式。
iPhone / iPad 手机上玩
苹果不允许网页直接看你手机屏幕。手机用「屏幕速聊」：快捷指令截屏 → 发到服务端 → TA 的回复弹在系统通知里；回到 Nano 后自动进聊天。
1
复制接口和令牌
快捷指令要 POST 到这个地址。令牌相当于密码，别发给别人。
2
在「快捷指令」里搭出这条流程
截图 → Base64 编码 → 获取 URL 内容 → 获取字典值 → 显示提醒
「获取 URL 内容」选 POST，地址填上面的接口；头部加 X-Peek-Token；请求体选「文件」，内容用下面「复制完整步骤」里的 JSON。
3
运行，然后回到 Nano
TA 的回复会先弹在系统通知里。等你回到小手机，这几轮会自动合并进角色聊天。
想更省事：设置 → 辅助功能 → 触控 → 轻点背面 → 双击 → 选这个快捷指令。服务端地址可以在下面「高级玩法」里改。
为什么这么麻烦？ 苹果只允许原生 App 读取屏幕，网页不行。快捷指令是苹果官方给出的唯一办法；「屏幕速聊」比直连 API 更省事，因为 Key 和人设都在服务端。

          方式 C · 屏幕速聊（服务端）
          

            
需要自己部署一个 Cloudflare Worker（`push-worker`）。没有服务端就用方式 B，或直接用上面的「粘贴屏幕文字」。

            
在任意 App 里双击「辅助触控」运行快捷指令：截屏 → 发到服务端 → 回复直接弹在系统窗口里、可继续打字；回到小手机后自动合并进聊天。

              快捷指令怎么搭：

              1) 截屏 → Base64 编码（关掉换行）；

              2) 获取 URL 内容：POST 到上面「接口地址」，头部加 X-Peek-Token: 你的令牌；

              3) 请求体选 文件，引用一个 文本 动作：

              {"chatId":"<角色ID>","image":"data:image/jpeg;base64,<截图base64>"}；

            不用填 system：Worker 会自动使用你当前选中的角色人设、最近聊天上下文和主 API。

              4) 获取字典值 取 reply → 显示提醒 弹出；

              5) 接着 要求输入 拿到你打的字，把 image 换成 text 再发一轮 → 循环，形成连续对话。
