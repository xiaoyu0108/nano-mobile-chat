查看 GitHub 详细教程（第一次用必看）
  1. 用手机或电脑浏览器打开 github.com，登录你自己的 GitHub 账号（没有就免费注册一个）。
  2. 点右上角头像 → Settings（设置）。
  3. 左侧菜单拉到最下面 → Developer settings。
  4. 依次点 Personal access tokens → Tokens (classic) → Generate new token (classic)。
  5. Note 填 Nano 云端备份；Expiration 选 90 days（不建议永久）；权限只勾选 gist，其它都不用勾。
  6. 点页面最下面的 Generate token，复制以 ghp_ 开头的令牌。它只显示一次，关掉页面就看不到了。
  7. 回到本页，把令牌粘贴到上面的输入框 → 点 连接 / 测试。成功后会显示你的 @用户名。
  8. 点 上传备份。程序会在你的 GitHub 里创建一个私有 Gist；每上传一次就是一个新版本，不会覆盖旧版本。
  9. 不再设置应用层大小限制：程序会把备份切成 8MB 的分片上传，恢复时按清单自动拼接。
    实际能存多大取决于 GitHub Gist（最多 300 个文件）和手机内存；特别大的备份建议同时保留本地导出。
  10. 换手机 / 重装后：粘贴同一个令牌 → 连接 → 在列表里点 恢复（会覆盖本机现有数据，请先确认）。
也可以使用 Fine-grained token：Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。 Resource owner 选你自己；Account permissions → Gists → Read and write；生成后复制 github_pat_ 开头的令牌。
令牌 = 你账号的 Gist 读写权限，只保存在本机浏览器，不会上传到任何服务器。建议专门建一个令牌，不用时回 GitHub 删除。 私有 Gist 只是“不公开”，GitHub 平台仍能看到内容；聊天记录很私密的话请自行评估是否上传。

查看 Cloudflare 详细教程（第一次用必看）
  1. 打开 dash.cloudflare.com，登录你自己的 Cloudflare 账号（免费注册即可；R2 需要绑定付款方式，但 10GB 免费额度内不扣费）。
  2. 左侧点 Workers & Pages → Create → Worker → 名字填 nano-backup → Deploy。
  3. 部署后点 Edit code，把编辑器里的默认代码全部删掉，粘贴下面这段代码，再点右上角 Deploy。
  4. 左侧点 Storage & Databases → R2 → Create bucket，名字填 nano-backups（R2 免费额度 10GB，需要先绑定付款方式，但在免费额度内不扣费）。
  5. 回到 Workers & Pages → 打开 nano-backup → Settings → Bindings → Add → R2 Bucket。 变量名必须填 BACKUP_R2，右边选择刚创建的 nano-backups，保存并重新部署。
  6. 不想开 R2 也可以继续绑 KV（变量名 BACKUP_KV），但单个备份仍限制 24MB；R2 没有这个限制。
  7. 还是在 Settings → Variables and Secrets → Add： 名称填 BACKUP_TOKEN，值填一串只有你知道的长密码（建议 24 位以上随机字符），类型选 Secret，保存并部署。
  8. 在 Worker 的 Settings → Domains & Routes 里确认 workers.dev 已启用，复制形如 https://nano-backup.xxxx.workers.dev 的地址。
  9. 回到本页：Worker 地址粘贴进去，密码填同一个 BACKUP_TOKEN → 点 保存并测试。
  10. 看到“已连接”后点 上传备份。以后换设备时，填同一个地址和密码，在列表里点 恢复。

R2 免费额度：10GB 存储，单个备份没有 24MB 限制（程序仍会先压缩）。 如果只绑了 KV，则仍有 24MB 单值限制；建议绑 R2 或使用 GitHub 备份。 备份多了请删旧的；占用可在 Cloudflare 的 R2 / KV 页面查看。
BACKUP_TOKEN 是这个备份接口唯一的密码，泄露后别人可以读写你的备份。 不要把它写进公开的 GitHub 仓库；怀疑泄露时到 Cloudflare 改掉并同步修改本页密码。 代码和数据都在你自己的 Cloudflare 账号里，作者服务器不参与。
云端备份会包含聊天记录、角色卡、图片等全部本机数据；恢复会覆盖当前数据且不可撤销。重要数据建议同时保留一份本地导出。
