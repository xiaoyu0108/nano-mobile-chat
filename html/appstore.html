创作指南

模板本身就是一个完整 App：首页 + 清单 + 二级页 + 设置 + 返回栈。照着改就行。

1. 复制模板
点「复制完整模板」，把整份 HTML 交给 AI，或自己改。
2. 描述你的应用
例如：「把清单换成记账，保留二级页和返回栈」。强调返回逻辑：首页 → AppStore；清单/设置 → 首页；二级页 → 上一页。
3. 高权限能力
Nano.chat / Nano.image.generate / Nano.files / Nano.gallery / Nano.tts / Nano.notify / Nano.clipboard / Nano.store / Nano.onBack。
4. 安装
把生成的 HTML 用「粘贴代码安装」贴进来，立刻运行。
